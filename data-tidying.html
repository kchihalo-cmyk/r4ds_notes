5.1 Introduction

5.1.1 Prerequisites

library(tidyverse)

5.2 Tidy data

You can represent the same underlying data in multiple ways. Tidy data is easier to read and work with.

There are three interrelated rules that make a dataset tidy:

  1. Each variable is a column; each column is a variable.
  2. Each observation is a row; each row is an observation.
  3. Each value is a cell; each cell is a single value.

The tidyverse packages are designed to work with tidy data. Example:

table1
# A tibble: 6 × 4
  country      year  cases population
  <chr>       <dbl>  <dbl>      <dbl>
1 Afghanistan  1999    745   19987071
2 Afghanistan  2000   2666   20595360
3 Brazil       1999  37737  172006362
4 Brazil       2000  80488  174504898
5 China        1999 212258 1272915272
6 China        2000 213766 1280428583

Compute the rate per 10,000:

table1 |>
  mutate(rate = cases / population * 10000)
# A tibble: 6 × 5
  country      year  cases population  rate
  <chr>       <dbl>  <dbl>      <dbl> <dbl>
1 Afghanistan  1999    745   19987071 0.373
2 Afghanistan  2000   2666   20595360 1.29 
3 Brazil       1999  37737  172006362 2.19 
4 Brazil       2000  80488  174504898 4.61 
5 China        1999 212258 1272915272 1.67 
6 China        2000 213766 1280428583 1.67

Total cases per year:

table1 |>
  summarise(
    total_cases = sum(cases),
    .by = year
  )
# A tibble: 2 × 2
   year total_cases
  <dbl>       <dbl>
1  1999      250740
2  2000      296920

Visualize changes over time:

ggplot(table1, aes(x = year, y = cases)) +
  geom_line(aes(group = country), color = "grey50") +
  geom_point(aes(color = country, shape = country)) +
  scale_x_continuous(breaks = c(1999, 2000)) # x-axis breaks at 1999 and 2000

5.3 Lengthening data

Pivoting transforms data into a tidy form: variables in columns and observations in rows.

The tidyr functions for this are:

  1. pivot_longer()
  2. pivot_wider()

pivot_longer() converts the columns beginning with wk into rows. The old column names are stored in a new week column, while the ranking values are stored in a new rank column.

  • cols identifies the columns to pivot.
  • names_to gives a name to the new column containing the old column names.
  • values_to gives a name to the new column containing the old cell values.

Structural missing values occur because of how the data is organized, rather than because an expected value is unknown. In the Billboard data, NA means a song was not in the Top 100 during that week. values_drop_na = TRUE removes these unnecessary NA rows when using pivot_longer().

To make computation easier, we can convert the values of week from character strings to numbers, using mutate() and readr::parse_number():

billboard_longer <- billboard |>
  pivot_longer(
    cols = starts_with("wk"),
    names_to = "week",
    values_to = "position",
    values_drop_na = TRUE
  ) |>
  mutate(week = parse_number(week))

5.3.2 How does pivoting work?

Suppose we have 3 patients, each with 2 blood pressure readings:

df <- tribble(
  ~id,  ~bp1, ~bp2,
  "A",  100,  120,
  "B",  140,  115,
  "C",  120,  125
)

We want our new dataset to have three variables: id (which already exists), measurement (the column names), and value (the cell values). To achieve this, we pivot df longer:

df |>
  pivot_longer(
    cols = bp1:bp2,
    names_to = "measurement",
    values_to = "value"
  )
# A tibble: 6 × 3
  id    measurement value
  <chr> <chr>       <dbl>
1 A     bp1           100
2 A     bp2           120
3 B     bp1           140
4 B     bp2           115
5 C     bp1           120
6 C     bp2           125
