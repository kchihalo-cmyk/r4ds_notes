Adding a geom. Note the + that connects the geom. Every layer must be connected with a +.

ggplot(data = penguins,
       mapping = aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point()

Adding an aesthetic (colour by species):

ggplot(
  data = penguins,

  geom_point()

ggplot(
  data = penguins,

6. What does the na.rm argument do in geom_point()? What is the default value? Create a scatterplot where you successfully use this argument set to TRUE.

na.rm controls whether missing values are removed silently. The default is na.rm = FALSE, which means R still removes the missing values but warns you that it did. Setting na.rm = TRUE removes them without the warning.

  geom_point(mapping = aes(color = species),
             na.rm = TRUE)

1.4 Visualizing distributions

How you visualize the distribution of a variable depends on the type of variable: categorical or numerical.

1.4.1 A categorical variable

A variable is categorical if it can only take one of a small set of values. To see the distribution, use a bar chart:

ggplot(penguins, aes(x = species)) +
  geom_bar()

To reorder the bars by frequency, use fct_infreq(). It works on categorical variables only.

ggplot(penguins, aes(x = fct_infreq(species))) +
  geom_bar()

1.4.2 A numerical variable

A variable is numerical if it can take a wide range of numerical values, and it is sensible to add, subtract, or take averages with those values. Numerical variables can be continuous (e.g. 39.1, 65.8) or discrete (e.g. 40, 38).

A common visualization is the histogram:

ggplot(penguins, aes(x = body_mass_g)) +
  geom_histogram(binwidth = 200, colour = "yellow")

A histogram divides the x-axis into equally spaced bins and then uses the height of a bar to display the number of observations in each bin.

The binwidth matters:

# terrible binwidth, hides the distribution
ggplot(penguins, aes(x = body_mass_g)) +
  geom_histogram(binwidth = 2000)
# not great either: too narrow, too many bars
ggplot(penguins, aes(x = body_mass_g)) +
  geom_histogram(binwidth = 20)

A density plot is an alternative to a histogram for a numerical variable:

ggplot(penguins, aes(x = body_mass_g)) +
  geom_density()

1.5 Visualizing relationships

To visualize a relationship, you need at least two variables mapped to aesthetics of a plot.

1.5.1 A numerical and a categorical variable

The distribution of body mass by species:

ggplot(penguins, aes(x = species, y = body_mass_g)) +
  geom_boxplot()

Or a density plot. Here we also customize the thickness of the lines with linewidth so they stand out more against the background.

ggplot(penguins, aes(x = body_mass_g, colour = species)) +
  geom_density(linewidth = 1)

Map species to both color and fill, and use the alpha aesthetic to add transparency. It takes values between 0 (completely transparent) and 1 (completely opaque).

ggplot(penguins, aes(x = body_mass_g,
                     fill = species,
                     colour = species)) +
  geom_density(alpha = 0.5)

1.5.2 Two categorical variables

Stacked bar plots show the relationship between two categorical variables:

ggplot(penguins, aes(x = island, fill = species)) +
  geom_bar()

For side-by-side bars:

ggplot(penguins, aes(x = island, fill = species)) +
  geom_bar(position = "dodge")

To compare proportions rather than raw counts (this might be better):

ggplot(penguins, aes(x = island, fill = species)) +
  geom_bar(position = "fill")

In these bar charts, the variable that will be separated into bars is mapped to the x aesthetic, and the variable that changes the colours inside the bars is mapped to the fill aesthetic.

Overriding the default “count” y label:

ggplot(penguins, aes(x = island, fill = species)) +
  geom_bar(position = "fill") +
  labs(y = "Proportion", x = "Island Name")

1.5.3 Two numerical variables

A scatterplot is the most common choice:

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point(colour = "magenta")
ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point(aes(colour = island))

1.5.4 Three or more variables

We can include more variables by mapping them to additional aesthetics. In this scatterplot, the colour of points represents species and the shape represents island.

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point(aes(colour = species, shape = island))

Too many aesthetics can clutter the plot, so we can use facets instead. Facets split the plot into subplots that each display one subset of the data. This works especially well for categorical variables.

To facet by a single variable, use facet_wrap(). Its first argument is a formula, created with ~ followed by a variable name. The variable you pass to facet_wrap() should be categorical.

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point(aes(colour = species, shape = island)) + # you can drop the shape aes
  facet_wrap(~island) +
  theme_bw() # just learnt of themes, yay!

ggplot(mpg, aes(x = displ, y = hwy)) +

  geom_point(aes(shape = year))
Error in `geom_point()`:
! Problem while computing aesthetics.
ℹ Error occurred in the 1st layer.
Caused by error in `scale_f()`:
! A continuous variable cannot be mapped to the shape aesthetic.
ℹ Choose a different aesthetic or use `scale_shape_binned()`.
ggplot(mpg, aes(displ, hwy)) +

For numerical variables, colour gives a gradient (light to dark), size gives small to large circles, and shape gives an error.

For categorical variables, colour gives distinct separate colours, size works but looks odd, and shape gives different symbols like circles, triangles and squares.

Numbers have order and magnitude, so aesthetics that can show order (colour gradient, size) work well. Categories are just labels with no order, so aesthetics that show distinct differences (separate colours, shapes) work better.
